# Countdown Timer Web Application

## 📌 Project Overview
The Countdown Timer is a web-based application that allows users to select a future date and time and displays a real-time countdown in days, hours, minutes, and seconds. When the countdown reaches zero, a completion message is shown along with sound and visual effects.

---

## 🚀 How to Use the Application
1. Download and extract the project ZIP file
2. Open the project folder in VS Code
3. Open `index.html` in any modern web browser
4. Select a future date and time using the date-time picker
5. Click **Start Countdown**
6. View the live countdown
7. When the timer ends, enjoy the alert sound and confetti animation
8. Click **Set New Timer** to start again

---

## ✨ Features
- Real-time countdown calculation
- Displays days, hours, minutes, and seconds
- Input validation for past dates
- Responsive and modern UI
- Alarm sound when countdown finishes
- Confetti animation on completion (optional enhancement)
- Reset option to start a new countdown

---
